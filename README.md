# F1 Prode — build web (Flutter)

Build estático de la app Flutter de F1 Prode publicado en GitHub Pages.

El código fuente está en [`f1prodeflutter`](https://github.com/jeffreydtz/f1prodeflutter). Este repo solo contiene el output (`main.dart.js`, `index.html`, assets) para servir la web.

## Relación con el resto del proyecto

| Repo | Rol |
|---|---|
| `f1prodeflutter` | App Flutter (móvil + web) |
| `f1prodedjango` | API Django en producción |
| `f1prodepython` | Backend Django inicial |
